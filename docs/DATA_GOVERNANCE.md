# Data Governance

- Tier 1 primary sources can independently support legal conclusions.
- Tier 2 official guidance provides interpretation/implementation context.
- Tier 3 research/secondary sources provide technical/scientific context only.
- Restricted/licensed sources are filtered before retrieval and never mirrored into the public corpus.
- Originals and source metadata are preserved.
- Every legal unit carries jurisdiction, citation, version, effective period, authority and access level.
- User memory is logically separated from legal evidence.
- User-provided private innovation data is never embedded into the shared legal corpus.

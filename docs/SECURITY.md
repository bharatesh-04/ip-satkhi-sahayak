# Security Baseline

- JWT/OIDC-compatible auth
- RBAC
- tenant isolation
- TLS in transit / encryption at rest in production
- retrieval-time access checks
- prompt injection defense: retrieved text is data, never instructions
- source hash/diff checks
- curator approval before Tier-1 publication
- immutable audit events
- restricted-source controls
- data minimization and user-controlled memory deletion

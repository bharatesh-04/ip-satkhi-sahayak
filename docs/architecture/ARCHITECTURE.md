# IP-SAKTI Sahayak — Architecture

## Controlled pipeline

User → Experience → API → Agentic Triage/Profile → Jurisdiction/Domain Routing → Hybrid Retrieval → Evidence Package → Multi-domain Reasoning → Trust/Verification → Action.

## Agentic policy

Agents handle semantic interpretation, dynamic routing and cross-domain reasoning. Deterministic services handle source authority, version status, permissions, audit, and safety gates.

## Data principle

Authoritative legal knowledge and user persistent memory are logically separated. User memory is context, never legal authority.

## International principle

Use a Global Framework plus reusable Country Profiles. Do not build one hard-coded AI per country.
